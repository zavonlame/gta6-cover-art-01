Neon Vice is a web app that turns one photo and one caption into a GTA 6-style cover poster. Choose from four panel layouts — Hero, Split, Trio, or Grid — place a photo in every panel and adjust it with zoom and pan, pick one of three colour grades (Vice Sunset, Neon Night, Palm Dusk), set the title in neon-glow lettering, and export the cover as a PNG in 1080x1080, 1080x1350, or 1920x1080. Hero puts a single photo front and centre with the title over it, Split and Trio balance two or three panels, and Grid gives four equal panels; every export is rendered at the exact pixel size, ready to post. Everything runs offline in a desktop browser as plain static files; where a panel has no photo, procedural synthwave art fills it in. Two sample photos are bundled in `app/samples/`, so you can build a cover without uploading anything, and the four screenshots in `screenshots/` show the editor and three finished covers.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
